## Quick Commands

- Matrix upload: `pio run -e captain_matrix_idf -t upload --upload-port COM4`
- Control upload: `pio run -e captain_control -t upload --upload-port COM5`

## Guarded Upload Commands (MAC-Locked)

- Matrix build (guarded wrapper): `powershell -ExecutionPolicy Bypass -File scripts/guarded-flash.ps1 -Target matrix -Action build`
- Matrix upload (guarded wrapper): `powershell -ExecutionPolicy Bypass -File scripts/guarded-flash.ps1 -Target matrix -Action upload`
- Control build (guarded wrapper): `powershell -ExecutionPolicy Bypass -File scripts/guarded-flash.ps1 -Target control -Action build`
- Control upload (guarded wrapper): `powershell -ExecutionPolicy Bypass -File scripts/guarded-flash.ps1 -Target control -Action upload`

Session safety rules:
- COM12/CrowPanel is hard-blocked in this workflow.
- Upload precheck uses immutable MAC identity from `scripts/flash-targets.json`.
- MAC mismatch blocks upload unless operator explicitly passes `-ForceMacMismatch`.

## Build Identity Standard

- Control firmware now prints build identity at boot:
	- `git=<short-hash>`
	- `state=<clean|dirty>`
	- compile timestamp (`__DATE__ __TIME__`)
- Build metadata is injected by `scripts/pio_build_meta.py` via PlatformIO `extra_scripts`.
- This is now a standard paired with guarded flashing: every baseline flash should be both MAC-guarded and version-identifiable from serial boot logs.
